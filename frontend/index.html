Seven agents

A team that hands work along, and shows its work.

Each agent has one job, a short list of tools it may use, and a check on its own output before the next agent starts.

  1. 01

    Discovery

    Reads Hacker News, feeds and the monthly hiring thread.

  2. 02

    Research

    Quotes the source. Marks every guess as a guess.

  3. 03

    Technical

    Looks for a public repository that matches the company.

  4. 04

    Qualification

    Scores by fixed rules. A model cannot set a score.

  5. 05

    Strategy

    Names a service only when the source states a need.

  6. 06

    Quality

    Checks the source URL and the fact-versus-inference split.

  7. 07

    Orchestrator

    Runs the order and answers people in the room.

Reconciliation

Why this company? The matcher shows its reasoning.

When a signal cannot be linked automatically, the desk lists each check that ran, the company it would pick and why, and what a person must verify.

  • Five classes, from confirmed to unmatched.
  • Only the company’s own website links a signal on its own.
  • Every decision goes into the audit trail.

Guardrails

Built to be hard to break.

The same checks run at every boundary, and a failure stops the run instead of passing silently.

Input

Size limits, private-address blocking, injected instructions fenced and flagged.

Tools

Each agent holds a short allowlist. No agent has a way to send a message to a company.

Output

A quoted fact must appear in the source. Model output is shape-checked and capped.

State

Only legal status changes. Approving or rejecting is reserved for a person.

Run

Budgets for model calls, tool calls, steps and time. A breach ends the run as partial.

Outreach

Requests to email, message or contact a company are refused, in every agent.
