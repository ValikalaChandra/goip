# Recording checklist

The automated film is already at `final-demo.mp4`. See `RECORDING_REPORT.md`. This list remains the manual fallback. Do not add Telegram to that film.

Before you press record:

- [ ] `GET http://127.0.0.1:8001/health` returns ok and Switch connected.
- [ ] Mattermost answers on port 50991.
- [ ] The overview still matches [the inventory](../fact-check/INVENTORY.md). If the counts moved, change the narration.
- [ ] Browser zoom is 100 percent. One window. No token on screen.
- [ ] Unrelated apps are closed. Notification banners are off.
- [ ] You know you will not press Run research, Confirm, Approve, Reject, or Draft.

Capture:

- [ ] Overview, wide and readable.
- [ ] Latest run, including the shortfall.
- [ ] Opportunities filtered to needs review, then Stitch.ai.
- [ ] Switch screen with the seven names.
- [ ] Switch Console, or a title that marks `gui-roundtrip.png` as an earlier exchange.
- [ ] Telegram only if the real chat is open and contains no secrets.

After the edit:

- [ ] 1920×1080, captions on, about 4 to 6 minutes.
- [ ] Every number in the voiceover is on screen or in the inventory.
- [ ] No shot implies an email was sent.
- [ ] The file is an MP4 you exported yourself. This repository does not contain one.
