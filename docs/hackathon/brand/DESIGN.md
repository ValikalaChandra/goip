# GOIP brand

One identity for the app, the card, the article, and the demo titles.

## Name

Global Opportunity Intelligence. The short mark is GOIP. The sidebar label is Opportunity desk.

## Colour

| Role | Value | Use |
| --- | --- | --- |
| Ink | `#14202b` | Text, sidebar |
| Accent | `#0c5f59` | The one action colour, and the freelance-fit zero on the social card |
| Paper | `#f6f3ec` | Social card |
| Desk | `#e7edf1` | App background |
| Panel | `#fbfcfd` | Cards and tables |
| Muted | `#526170` | Secondary text |

High priority is navy. Qualified is a lighter blue. Needs review is sand. Those colours describe stored status. They are not a quality score.

## Type

Headlines use Iowan Old Style, then Palatino, then Georgia. Interface text uses Avenir Next, then Segoe UI. Numbers are tabular.

## Mark

A rounded square with the letter G. In the app it sits on the accent colour inside the ink sidebar.

## Voice

First person. Name the source. Say when a number is a stored label from the first scorer. Do not call a research candidate a client.
